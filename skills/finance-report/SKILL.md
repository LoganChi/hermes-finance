# 财经报导 · Phase 1 搜索提炼指引

> ⚠️ 边界声明：本指引**仅在报告管线的 Phase 1（搜索提炼）可见**。
> 你这一阶段的**唯一产出是搜索笔记**（2000-4000 字），存入 memory 后作为纯文本返回。
> **不要**创建飞书文档、不要生成图片、不要写最终报告正文或总结——这些由后续阶段的独立 LLM 负责，你影响不到。
> 完整流程图与设计说明见同目录 `flow.md`（供维护者阅读，你无需关心）。

## 笔记必须按这 6 个财经维度组织

笔记结构直接决定最终报告形态（后续阶段会顺着笔记结构写正文）。**每个维度 3-5 条要点，必须带具体数字与时点**：

1. **市场总览**：上证 / 深证 / 创业板 / 科创50 收盘点位与涨跌幅、两市成交额、北向资金净流入。
2. **要闻速递**：政策与监管动向、重要宏观数据（CPI / PMI / 社融 / LPR）、重大公司事件。每条标日期。
3. **板块异动**：领涨 / 领跌板块及龙头股、驱动事件。参照申万一级行业分类。
4. **数据看板**：人民币汇率（在岸 / 离岸）、关键商品（原油 / 黄金 / 铜）、外围市场（美股 / 纳指 / 恒生）。
5. **后市展望**：**机构观点**与市场共识方向，标注机构名。**不预测具体点位**。
6. **风险提示**：地缘、政策、流动性、黑天鹅信号。

## 数据源路由（核心）

按维度分配采集来源，**优先用批量接口省 web_fetch 配额**（全管线最多只能 web_fetch 3 个页面）：

| 维度 | 采集方式 |
|------|----------|
| 实时行情 / 指数 / 个股 | 调 `web_fetch` 腾讯批量接口，**1 次拿全**：<br>`https://qt.gtimg.cn/q=sh000001,sz399001,sz399006,sh000688,sh600519`<br>返回字段索引见同时注入的 stock-data 指引 |
| 财经快讯 / 政策 / 宏观数据 | `web_search` 搜「财联社 今日」「华尔街见闻 快讯」「金十数据」「{日期} 财经要闻」 |
| 汇率 / 商品 / 外围 | `web_search` 搜「人民币汇率 今日」「布伦特原油」「黄金价格」「美股 收盘」 |
| 板块 / 行业深度 | 若消息同时命中 macro-sentinel，其 NewsNow 财经源指引已在上方，按其维度补充舆情 |

**web_fetch 3 次预算建议**：
- 第 1 次 → 腾讯批量行情（拿全指数 + 龙头个股）。
- 第 2 次 → 深度要闻全文（挑 1 篇高质量分析）。
- 第 3 次 → 兜底（汇率 / 商品专项，或补充遗漏维度）。

## 财经红线（不可违反）

- **数据必须标注时点**：行情写「收盘」或「盘中 HH:MM」；宏观数据写发布日期。
- **URL 不要内联进叙述**：写「据财联社 X 月 X 日报道」，**不要**在笔记正文里嵌 `http://...`。所有候选 URL 集中列在笔记**末尾的「候选来源」区**——后续阶段只允许在「参考来源」章节放 URL，你内联进去会触发违规。（管线代码 `StripFeishuUrls` 会剥离所有飞书文档链接，历史会话残留的飞书 URL 一律忽略。）
- **不预测具体股价 / 点位**：展望只转述机构观点，不给「目标价 XX」。
- **不编造数据**：接口失败或搜不到，该维度写「数据暂缺」，不要填估数。
- 笔记末尾附一句免责声明：「本报导仅供研究参考，不构成投资建议。」

## 与共存 skill 的协调

若本消息同时命中 stock-data / macro-sentinel，它们的接口指引会跟本指引一起出现在上方 prompt 中：

- 行情 / 个股的具体接口参数、字段索引 → **用 stock-data 的指引**，本指引不重复。
- 舆情 / 热点的多源采集方法论 → **用 macro-sentinel 的指引**。
- 本指引只负责**维度编排 + web_fetch 预算分配 + 财经红线**，不与它们抢数据采集细节。
